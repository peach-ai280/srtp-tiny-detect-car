## 本地目录结构

```
dataset/
  v1.0/
    images/            000001.jpg …            800 张
    labels/            000001.txt …            YOLO 格式
    classes.txt        0 material_box
                       1 obstacle
                       2 hand
    splits/            train.txt / val.txt / test.txt
    manifest.sha256
```

**存放位置**：本地 + 一个异地备份（网盘/移动硬盘）。**只存一个地方等于没存。**

## 标注格式

YOLO txt，每行 `class_id cx cy w h`，归一化到 0–1，6 位小数：

```
0 0.482300 0.611100 0.152400 0.233800
1 0.781000 0.402500 0.410000 0.890000
```

**类别只有 3 个。** 类别一多，小模型训不动，而且我们的目的是验证"判定器有没有用"，不是刷精度。

| id | 名称 | 说明 |
|---|---|---|
| 0 | material_box | 物料盒，主要目标，**避障的主要对象** |
| 1 | obstacle | 其他障碍（椅子腿、纸箱、水瓶） |
| 2 | hand | 人手——**专门用来测误检**（模型容易把人手当成物料盒） |

## 采集要求

| 维度 | 要求 | 为什么 |
|---|---|---|
| 光照 | 白天自然光 / 日光灯 / 逆光窗边 / 侧向强光 | **逆光是判定器最该起作用的场景** |
| 角度 | 正对、侧 45°、俯视、低角度 | 低角度框会变形 |
| 距离 | 15 / 30 / 50 / 80 cm | 对应"要停 / 该减速 / 可通过"的决策边界 |
| 背景 | 桌面、地板、走廊、有杂物 | 干净背景训出来的模型一到真实环境就废 |
| 困难样本 | 运动模糊、部分遮挡、反光地面、纯色墙 | 判定器要识别这些 |
| **负样本** | 画面里没有目标的帧，≥ 10% | 没有负样本，模型到处乱框 |

---

## 划分规则

- 按**采集批次**划分（不是随机按帧），防止同一场景一半在 train 一半在 val
- 70 / 15 / 15
- 生成后写进 `splits/`，**入库，之后不许重划**
- val 用于阈值标定，test 只在最后用一次
