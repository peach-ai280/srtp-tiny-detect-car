## 定位：这不是学校要的东西

先说清一件容易搞混的事：**立项、中期、结题的验收清单里，没有论文，也没有专利。**

学校要的是：11/30 选型清单 + 环境跑通、2/19 量化、4/14 上板、6/16 中期、7/15 指标、8/15 结题报告。**这些没有一项是"论文已发表"或"专利已授权"。** 论文和专利没做出来，结题照样能过。所以：

- **它不是交付物，不做不扣分；**
- **但它是我们自己认下的事。** 九个月做出来的东西，应该留成别人能引用、能查证的形式——结题报告只对学校负责，论文和专利是对外说话的东西。

两条纪律由这一条定位推出来：

1. **排期冲突时，让路的是这份文件。** 课业、考试、项目节点，任何一样比这里的日期优先。
2. **不为了赶投稿压缩实验。** 跑出来的数字不齐，就不写；写了也是废稿。

## 二、三个候选选题（按可行性排序）

### 选题 A（首选）：量化饱和率作为 MCU 端检测的可信度判据

| 项 | 内容 |
|---|---|
| **一句话** | INT8 部署后激活值撞上量化区间边界的比例，能否作为帧级可信度的有效判据 |
| **对应创新点** | ① ｜ **类型**：方法型（有对照、有曲线、能证伪） |
| **核心图表** | 风险—覆盖率曲线（四条：S1 / S4 / 不含 S2 / 含 S2） |
| **卖点** | 这个信号只在部署后存在，浮点研究里看不到；工程实践里知道它，但没人拿它当判据 |
| **风险** | Cube.AI 上可能只拿得到输出层；若只有输出层，结论要相应收窄 |
| **能不能立住** | 数据说了算。S2 的净贡献弱，题目就改成"×××的有效性边界"，仍是论文，只是不惊艳 |

### 选题 B：从融合权重到融合时机——触发式定向复核

| 项 | 内容 |
|---|---|
| **一句话** | 把"什么时候唤醒第二个传感器"交给模型的置信度输出决定，而不是固定权重或固定时序 |
| **对应创新点** | ② ｜ **类型**：系统/方法混合 |
| **核心图表** | 误动作率对比（基线 vs 本方案）、触发率—召回散点、时延分解 |
| **卖点** | 结构层面的改动，代价模型清楚（平均功耗降、最坏时延升），可量化 |
| **风险** | 误动作率靠人工标注，标注一致性会被审稿人质疑 → **必须写清标注流程与一致性** |
| **能不能立住** | 取决于"降 50%"这个目标。降不到就报真实值，并讨论原因 |

### 选题 C：算力受限平台上的帧间补位实现与收益量化

- **一句话**：4 fps 视觉 + 100 Hz 惯性的定点实现，收益到底多大。
- **类型**：工程型（**最难发**）。方法本身是成熟常识，审稿人一句"这是已知技术"就能拒。
- **建议**：**不作为独立论文**，作为 A 或 B 的一节（"系统实现"），或写成工程类期刊的技术报告。

## 四、投稿纪律：一稿一投，没有余地

**"能不能同时投几家，看哪家先过？"——不能。** 这不是策略，是学术不端。

- 同一篇稿子同时投两家，叫**一稿多投**。中文期刊之间有互查机制，被查到会**通知学校**。
- 判断标准很机械：**收到明确拒稿通知、或正式撤稿确认之前，不能投第二家。**

**"投多篇"指的是内容不同的多篇**，不是同一篇多投：

| 可以 | 不可以 |
|---|---|
| 一篇讲"饱和率作为判据" | 同一篇同时投两家 |
| 一篇讲"触发式复核的系统实现与实测" | 一篇拆成两篇、图和数据重叠（"香肠论文"，一样被拒） |
| 会议版发表后，扩展 30% 以上再投期刊（须引用会议版并说明） | 中文已发表后，原样改英文再投 |

**顺序别错**：一篇工作只能"首发"一次。先在中文期刊发表，就等于公开了，再改英文投 SCI 基本会被拒（出版记录可查）。

> **想走英文线，就英文先投；中文是退路，不是第一站。**
> 经费没落实、只走中文线，那就直接投，不用纠结。

## 六、专利：撞在哪、怎么绕

### 6.0 三件必须先说清的事

**第一，撞不撞车不影响受理。** 流程是：提交 → 形式审查（文件齐不齐）→ 受理通知书（约一周）→ 之后才谈实质问题。**形式审查不看新颖性**，所以哪怕撞得一件不剩，受理通知书照样发。撞车影响的是"最后能不能授权"。

**第二，撞车不是撞一个点，是看全面覆盖。** 对方权利要求里的**每一个技术特征**你都有，才算撞。少一个、或多出一个区别特征，就不构成。所以绕开不是靠把细节改得不一样，是靠**换一个技术特征当发明点**。

**第三，方向不用改，但要换专利的落点。**

| 如果发明点定在 | 结果 |
|---|---|
| "用可靠性决定要不要复核" | **绕不开。** 这条链汽车行业申请了二十年，改任何细节都在里面 |
| "这个可靠性从哪来、拿到之后怎么用" | **是新的。** 这是能守住的 |

项目方向一个字不用改（还是三档 + 复核 + 补位）。变的只是：专利保护的不是那个流程，而是流程里**"只否决不重算"**这一条——"信号从哪来"已经不能单独当发明点了（见 6.1 末段）。

### 6.1 撞车清单

这七件是查到的、与我们的思路重叠的中国专利。**前四件说明一件事：`置信度低 → 动第二传感器 → 降级` 这条链，汽车行业早就申请完了。**

| 公开号 | 权利人在做什么 | 重叠点 | 威胁 |
|---|---|---|---|
| **CN115771525B** | 通用汽车：二级传感器 → 冗余检验 → **跛行回家（减速停车）**，2026-03-24 授权 | "冗余传感器 → 降级模式"几乎逐字对应 | ⚠️⚠️⚠️ |
| **CN114564003A** | 东风：给每个传感器分配场景置信度，低于阈值换辅传感器再比权重 | "置信度阈值决定用哪一路" | ⚠️⚠️⚠️ |
| **CN121291496A** | 奇瑞（2025-11 申请，2026-01 公开）：多模态置信度 → 抑制不可靠模态 → 安全停车 | "模态置信度 → 抑制 → 停车" | ⚠️⚠️ |
| **CN119881816A** | 深圳承泰：毫米波雷达判疑似虚假目标 → **超声波二次确认** | "雷达/视觉 + 超声二次确认" | ⚠️⚠️ |
| **CN121119003B** | 把**饱和率**列为量化误差指标之一，用于筛量化敏感层、回退精度 | "饱和率"这个词进了权利要求 | ⚠️⚠️（用途不同） |
| **CN120893455A** | 运行期提取激活聚集性 + 反向梯度衰减 → 融合成"饱和风险预测指数" → 超阈值**自动触发解饱和调控** | 运行期饱和 → 分级 → 触发动作，三步齐全 | ⚠️⚠️⚠️ |
| **CN113255877B** | 预测量化后每层算术溢出频次，超阈值就放大数值范围重算映射 | "溢出频次当指标 + 阈值判断" | ⚠️⚠️ |

> **CN120893455A 要看清**：它（2026 年公开，任务是机器翻译）把"运行期饱和 → 分级 → 触发"写进了权利要求。专利审查不看应用场景，看技术方案，所以"我们做检测、它做翻译"不是有力区别。
> **但两处区别是硬的**：① 它的判据要算**激活分布聚集性 + 反向梯度**，是两条独立统计支路，有实打实的算力；我们读的是量化算子**内部本来就在维护的溢出计数器**，零支路。② 它触发的是**调量化参数**，我们触发的是**外部传感器物理复核 + 降级**。

#### 6.1.1 2026-10-31 补检：非专利文献把"读饱和率"占了

**原先的判断要改。** 把"读量化裁剪比例"当**运行时**信号这件事，非专利文献层面已经被占了：

| 文献 | 它做了什么 | 与我们的差别 |
|---|---|---|
| **QMA**（Springer，DOI `10.1007/978-3-032-38806-3_27`，© 2027） | **每次推理**从"哨兵激活层"取三个健康信号，**第一个就是 Clipping Ratio**；用 LinUCB 在这些信号上选纠正动作（调输入尺度 → 整模型重转换） | 它**修模型**，我们**定决策**；它的结论交给下一轮推理，我们的交给底盘动作 |
| **When Clipping Deletes Evidence**（Zenodo 18748352，2026） | 提出 "shadow signal"，**记录超出 clip 边界被丢弃的溢出质量**当诊断信号 | 离线诊断，未接运行时门控 |
| 公开工程教程（`clipped_count / total_count`） | 直接把裁剪占比当监控指标打点 | 只打点告警，不做决策 |

**所以第 ① 条权利要求要拆成两半看：**

- "**读饱和率当信号**"这一半：**已被公开**，单独写必被驳（QMA 是最直接的对比文件）。
- "**零额外计算支路**"这一半：仍成立，但只能作为**有益效果**写，不能当撑独权的技术特征——QMA 读这个数时也没有另开计算支路。

**能活的是第 ② 条**：复核**只投否决票、不修改置信度、不重算、不改量化参数**。检索范围内没有中文专利占据这一点，而且有 BCEA 的 13 个百分点实验支撑（串行重算会让错误率超出目标）——这在专利上叫"克服技术偏见"，比"零算力"的创造性论证硬得多。

**独权建议这样组合**（顺序即重要性）：

1. **只否决**：复核结果仅具否决权，不改分、不重算、不改量化参数
2. **取信号**：写成限定条件（"计数由量化算子执行时产生，不引入额外计算支路"），不写成发明点
3. **三档出口**：W／U／R + 减速指令
4. **预算限缩**：单帧 ≤150 ms 内完成，且不依赖反向传播梯度

> 一句话：**"零额外算力"从独权里挪到有益效果段；独权靠"只否决不重算"站住。**

### 6.2 原方案哪几条保不住

原稿写的是：① 分级触发（可信度决定是否唤醒第二传感器）② 定向复核（按框方位限定测距角度）③ 保守判定（不一致取更近）④ 可信度有一分量来自饱和率。

- **第 1 条，废。** CN115771525B + CN114564003A 已把"置信度决定用哪一路、什么时候降级"占死。
- **第 2 条，弱。** "按方位限定角度"是常规工程手段，撑不住独立权利要求，只能当从属。
- **第 3 条，能用。** "不一致取更近而非取平均"是具体且反常规的选择——常规做法都是融合。
- **第 4 条，被咬一半。** CN121119003B 把饱和率写成量化误差指标，但用在**训练期选层**，不是**运行期判帧**。这个区分必须写进权利要求。

### 6.3 改后的写法：不争"决策链"，争"信号来源"

**① 触发量的来源是量化过程本身，不是模型输出**

> 一种嵌入式视觉感知的可靠性判定方法，其特征在于，判定所依据的可靠性度量，取自定点神经网络推理过程中激活值落入量化区间边界的样本比例；该比例由推理算子内部统计得到，**不增加独立计算支路、不改变模型参数、不需要额外标注数据**。

技术效果是实的：零额外算力、零额外内存、M7 上实时可拿。而 GM / 东风的方案依赖"模型输出分数"或"场景先验分配"，取信号路径不同。

**② 复核结果只作否决，不改写原分数**

> 其特征在于，第二传感器的复核结果仅用于否决第一传感器的判定结论，**不参与原可靠性度量的修正**，从而保持原判定阈值的标定条件不变。

这条对应 2026 年 BCEA 指出的问题（介入取证会破坏可交换性，实测风险超目标最多 13 个百分点）。**查过了，还没有中文专利占这个点**——最新、最干净的一条，建议作主权利要求。

**③ 不一致时取更近**（对应原第 3 条）

> 两路结论不一致时，按测得距离更近的一路执行。

**④ 三档 + 帧间运动学补位**

> 判定为"禁用"时，用上一帧目标位置结合轮速与航向角变化推算本帧目标应处区域，作为独立于检测模型的一致性检验。

### 6.4 四条硬约束

**约束一：只申发明专利。** 实用新型只护硬件构造，而我们的价值在方法——花一千块护"板子上插了摄像头和超声"，别人换个接法就绕开。软著只证明"这堆代码是我写的"，对方法没有保护力，能申但不急。

**约束二：申请人写"重庆大学"，不写个人。** 这是职务发明的规定，也决定以后能不能算学校的成果。操作上走学校科技处/资产公司的通道，**提交前办完**，不能先自己交再改。

**约束三：受理不等于授权。** 受理通知书只证明文件收到了。项目周期内最多拿到受理通知书，结题材料里不写"专利已授权"。

**约束四：交代理人之前，先花几百块做一次正式检索。** 本轮用的是网络检索（公开网页 + 检索式），**只能初筛**：覆盖不到审查员用的内部库，读不到权利要求全文。必须让代理机构用专业库查两件：

1. **CN121119003B 的权利要求全文**——"饱和率"的保护范围到哪，是不是只限训练期选层。

## 七、写作纪律

1. **数据必须能追到实验记录。** 论文里每个数字对应一个 EXP 编号，被问时能翻出来。
2. **不写没做的事。** 没做的实验不写"初步验证了"；做不到的指标不写"基本达到"。
3. **AI 只用于润色与翻译**，按 [AI 使用规范](../05_规范/01_AI使用规范.md) 第三节声明。**正文段落不许由 AI 生成后不加核对。**
4. **引用逐条核原文。** AI 编造文献是常态，我们已经踩过一次（见 [文献调研报告](../01_立项/04_文献调研报告.md)）。
5. **负结果照写。** "S2 没有带来显著判别力"如果是结论，就写进结论——比硬凑正结果体面，也更可能被接受。

**署名**按 [团队章程](../04_团队/01_团队章程.md) 第五节，看"实际贡献 + 能否讲清"，结题前一个月公示一次，48 小时内可提异议。**执笔只有一个人**，其余人提供数据、图表与自己那一节的初稿。
