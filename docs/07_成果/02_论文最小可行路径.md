## 二、那三张图长什么样（这是论文的骨架）

### 图 1 · 判别力（最重要）

- 横轴：判为"不可信"的帧比例（拒绝率，0→100%）
- 纵轴：被拒绝的帧里，真正判错的比例（或反过来：漏掉的错误比例）
- 三条线：**饱和率 / softmax 熵 / 最高框分数**
- 一句结论：*"在同等拒绝率下，饱和率能多捞出 X 个百分点的错误帧"*

**这张图决定论文能不能发。** 如果三条线几乎重合，说明饱和率没用——那时改写成"饱和率并不优于输出置信度"的负结果，也是一篇，但要换刊物定位。

### 图 2 · 阈值漂移

- 横轴：不同场景切片（白天/逆光/夜间/模糊）
- 纵轴：为了达到同一个错误率目标，阈值要挪多少
- 一句结论：*"固定阈值在换光照后失效，必须按分位点重标定，漂移量约 X"*

**这张图是防守用的**：评委一定会问"阈值怎么定的、换批数据还成立吗"，这张图就是答案。

### 图 3 · 位宽/分辨率扫描

- 表：FP32 / FP16 / INT8 × 输入分辨率 320 / 416 / 640，各自的 mAP、饱和率均值、推理时间
- 一句结论：*"精度掉 X 个点，饱和率均值从 A 涨到 B"*

**这张表证明"饱和率不是噪声，它随量化强度单调变化"**——这是整个方法的前提。

## 三、W3 怎么做：两个方案

### A 方案（首选，最贴题）：TFLite 读中间层

TFLite 的 INT8 模型里，中间张量本身就是 int8。**直接读它，统计有多少个值顶到了 0 或 255**——这就是饱和率的物理原型，也是"零额外算力"这句话的现实依据（因为这些值本来就被算出来了，你只是读了一下）。

```python
import numpy as np, tensorflow as tf

interp = tf.lite.Interpreter(model_path="model_int8.tflite")
interp.allocate_tensors()

# 找出所有 int8 的中间张量
details = interp.get_tensor_details()
int8_tensors = [d for d in details if d["dtype"] == np.int8
                and len(d["shape"]) >= 2]

def saturation_of(arr):
    """落在量化区间两端的比例。0 和 255 是 INT8 的边界。"""
    n = arr.size
    if n == 0:
        return 0.0
    return float(((arr == -128) | (arr == 127)).sum()) / n

# 跑一帧
interp.set_tensor(interp.get_input_details()[0]["index"], img)
interp.invoke()

# 逐层读，算每层饱和率，再取平均或最大值
rates = []
for d in int8_tensors:
    try:
        arr = interp.get_tensor(d["index"])
    except Exception:
        continue          # 有些张量不可读，跳过，不影响结论
    rates.append(saturation_of(arr))

frame_saturation = float(np.mean(rates))   # 每帧一个数
```

**注意三件事**：

1. **0/255 还是 -128/127，取决于模型的零点设置。** 先打印一个张量的 `quantization` 参数确认，别照抄。
2. **不是所有张量都能读**，`get_tensor` 会抛异常，用 try 包住。
3. **只统计卷积层/激活层输出**（形状 ≥2 维的），不要统计权重张量。

### B 方案（W3 卡住时的退路）：PyTorch 里手算

不用真量化，用模型自己算出来的 scale 模拟一次"如果量化，会饱和多少"：

```python
sat = ((x >= xmax_clip - 1e-6) | (x <= xmin_clip + 1e-6)).float().mean()
```

`xmax_clip / xmin_clip` 用校准集上统计的分位数（比如 99.99% 分位）。**这不完全等价于真量化，但能出图、能写论文**，代价是要在论文里写明"模拟量化"。**这是退路，不是首选。**

## 四、四种翻车情况，各自怎么收

| 情况 | 说明 | 怎么收 |
|---|---|---|
| **饱和率分不开对错**（AUROC ≈ 0.5） | 假设不成立 | 换成"三信号融合"，或改写成负结果论文：《饱和率作为逐帧可信度信号的有效性边界》。**照样能投，题目换掉** |
| **饱和率比分数还好**（AUROC 明显更高） | 最好的情况 | 论文主线成立，可以冲高一点的刊 |
| **三个量差不多** | 最常见 | 卖点改成"零额外算力"——**效果一样但不需要额外计算**，这在 MCU 上就是全部价值 |
| **INT8 精度崩了**（掉 10 个点以上） | 模型/校准集问题 | 换校准集（用真实场景图，别用 ImageNet）；降分辨率；减类别。**不要改网络结构** |

**这四种里有三种都能出论文。** 唯一出不了的是"你没跑完"。
