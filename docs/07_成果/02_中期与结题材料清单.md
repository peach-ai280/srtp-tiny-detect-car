# 中期与结题材料清单

> 两张清单，对着勾。**清单不是形式——它会逼你在截止前发现"那个数还没测"。**

---

## 一、中期检查（2027-06-16）

按 M4 的验收标准，需要能**现场演示**。演示比材料更硬——演示垮了，材料写得再好也没用。

### 1.1 材料

- [ ] 中期报告（结构见下）
- [ ] 进度对照表：计划 vs 实际，**延期的写明原因与新日期**
- [ ] 演示视频（3 分钟，含一次真实的"存疑 → 降速 → 复核"）
- [ ] 下一阶段计划（M5/M6 的具体动作）
- [ ] 经费使用情况（材料费 450 / 测试加工 350 / 印刷 200）

### 1.2 中期报告结构

```
1. 项目概况（题目、成员、周期、目标）
2. 已完成工作（按里程碑组织，每条附交付物位置）
3. 关键数据（时延、帧率、内存、触发率、mAP——已测的填，未测的写"未测"）
4. 与计划的偏差（延期、指标未达、方案调整，逐条说明）
5. 遇到的问题与解决（至少写两条真实卡点）
6. 下一阶段计划（M5/M6，带日期与验收标准）
7. 经费使用
8. 附件（实验记录索引、代码仓库地址、演示视频链接）
```

**第 4 节是评审最看重的。** 全都顺利的项目通常意味着两种可能：要么没干，要么没说真话。

### 1.3 演示准备（提前一周开始，别当天现调）

- [ ] 演示脚本写成一页，排练 ≥ 3 次
- [ ] **包含一次故意触发复核**（否则评委看不到创新点）
- [ ] 电池充满，带备用电池
- [ ] 场地提前踩点：地面反光？光照？有没有干扰（无线、强光）
- [ ] 失败预案：如果现场跑不通，播视频 + 讲数据（**提前准备好这个 Plan B**）

## 二、结题（2027-08-15）

### 2.1 必备材料

- [ ] 结题报告（结构见下）
- [ ] 源码包（仓库地址 + 一个打好的 zip，防止仓库失效）
- [ ] 实测数据表（`results/指标表_*.csv` 汇总）
- [ ] 部署流程文档（**别人照着能跑**）
- [ ] 数据集说明与数据卡
- [ ] 演示视频 + 现场演示
- [ ] 论文投稿证明 / 专利受理通知书（有就给，没有如实说明）
- [ ] 经费决算

### 2.2 结题报告结构

```
1. 摘要（300 字，含最关键的两个数）
2. 研究背景与意义
3. 国内外研究现状（引用 13 篇 + 开源项目，用坐标表说明我们的位置）
4. 研究内容与方法
   4.1 系统架构
   4.2 帧级可信度判定（含对照实验设计）
   4.3 触发式定向复核
   4.4 帧间运动学补位
5. 实验与结果
   5.1 实验平台与数据集
   5.2 模型部署结果（时延、内存、帧率）
   5.3 判定有效性（风险—覆盖率曲线，四组对照）
   5.4 触发复核效果（误动作率、漏检代价、时延）
   5.5 帧间补位收益（A/B 两组）
   5.6 功耗—温升—帧率包线
6. 讨论
   6.1 不可信判定的有效性边界（★ 负结果放这里）
   6.2 局限与未完成项
7. 结论
8. 参考文献
9. 附录（实验记录索引、代码结构、AI 使用声明）
10. 致谢
```

**第 6 节是这份报告的价值所在。** 大一的结题报告大多只写"我们做成了什么"，写清"在什么条件下不成立"的很少。这一节会让报告看起来不像学生作业。

### 2.3 最后的硬验收

- [ ] **找一个没参与项目的人，只照文档做一遍**，能跑出结果
      （做不到就说明文档不够，回去补——这是最硬也最容易被跳过的一条）
- [ ] `git tag m6-final` 打好
- [ ] 仓库 `README` 的"现在到哪一步"更新为最终状态
- [ ] 所有"待填""待补"清空，或明确标注"未完成 + 原因"

### 2.4 结题后

- [ ] 数据集与模型按学校要求归档或销毁（涉及隐私的部分必须处理）
- [ ] 仓库保持可访问（保研材料要用；导师很可能会点进来看）
- [ ] 交接给下一届（如果有学弟接手，写一份"从哪继续"的说明）

## 三、常见翻车点

| 翻车 | 什么时候发现 | 怎么避免 |
|---|---|---|
| 演示当天跑不通 | 当天 | 提前一周排练 3 次；准备视频 Plan B |
| 指标没测全 | 结题前一周 | 对着 [验收清单](../03_技术方案/06_指标定义与验收口径.md) 每月勾一次 |
| 数据对不上（表里的数和日志不一致） | 写报告时 | 每个数当场入库，不靠回忆补 |
| 别人跑不起来 | 结题时 | 结题前一个月做"陌生人复现"测试 |
| 报告写不出"讨论" | 最后一周 | 每次实验完就写 200 字分析，攒着最后写必崩 |
| 经费票据不全 | 报销时 | 每笔采购当天拍照存票据，别攒 |
