# 变更记录（项目级）

> 这里记**项目层面的变更**：里程碑、分工、指标口径、方案的实质调整。
> 代码与文档的逐条改动看 `CHANGELOG.md` 和 `git log`，不在这里重复。

---

## 什么必须记

| 记 | 不用记 |
|---|---|
| 里程碑日期或验收标准改了 | 修了个错别字 |
| 分工调整（模块换人） | 文档补了一段说明 |
| 指标口径改了（哪怕只改一点点） | 代码重构（不改行为） |
| 砍掉/新增一个创新点 | 依赖版本升级 |
| 申报书里的承诺与现在不一致 | 目录结构调整 |

**判断标准**：三个月后有人问"当初不是说要做 X 吗"，这条要不要能被解释？

---

## 记录格式

```markdown
### YYYY-MM-DD · 一句话说明改了什么
- 类型：里程碑 / 分工 / 指标 / 方案 / 范围
- 原：……
- 改：……
- 理由：……
- 影响：受影响的文档、代码、已测得的数据要不要重做
- 决定方式：负责人决定 / 组会通过 / 指导教师建议
```

## 变更列表

### 2026-10-26 · 建立仓库，项目管理正式启动

- 类型：范围
- 原：立项阶段的材料散落在本地文件夹（PPT、讲稿、申报截图、文献 PDF）
- 改：建立 `srtp-tiny-detect-car` 仓库，文档体系化；数据与大文件不入库
- 理由：四个人跨九个月跨学期，本地文件夹无法追溯"这个数怎么来的"
- 影响：后续所有交付物进仓库；[记录规范](../02_过程记录/00_记录规范.md) 从此生效
- 决定方式：**待首次组会通过**（议题见 [2026-10-26 组会议程](../02_过程记录/会议记录/2026-10-26_建仓与立规矩.md)）

### 2026-10-26 · 起草《实验室规矩》v0.9（待组会通过）

- 类型：范围
- 原：无成文约定，靠口头
- 改：请销假、病假与工作协调、无故缺勤、消极怠工、滥用 AI、模块熟悉度六类事项成文，后果落在署名与模块归属
- 理由：真发生的时候再定规矩，就变成了人际问题
- 影响：[分工与交接](../04_团队/03_分工与交接.md)、[风险登记册](01_风险登记册.md) 第五节的记录栏启用
- 决定方式：**待首次组会通过**。起草时已知争议点是"记黄牌会不会太严"，条款里预留了"每学期末复盘，执行不下去的删掉"，会上确认

### 2026-10-26 · 硬件方案定为双板架构

- 类型：方案
- 原：申报书只写"STM32"，未定具体形态
- 改：F103C8T6（底盘，已有）+ STM32H743VIT6 核心板（感知，新增）
- 理由：见 [ADR-0001](../02_过程记录/决策记录/ADR-0001_双板架构.md)（F103 内存差一个数量级；保住已验证的底盘；调试效率）
- 影响：材料费 +130 元（总 178 元 / 额度 450 元）；M1 验收增加"两板串口往返延迟实测"
- 决定方式：负责人提出，组会通过

### 2026-10-26 · 评价指标改为"误动作率 · 漏检代价 · 平均决策时延"，mAP 降为基线

- 类型：指标
- 原：申报书写"识别精度与帧率满足实时性要求"
- 改：四个主指标（见 [指标定义](../03_技术方案/06_指标定义与验收口径.md)），mAP 只用于证明模型没退化
- 理由：mAP 是平均值，撞车是极值事件；且原指标无法证伪创新点 ②③
- 影响：**M4 前必须采集单视觉基线数据**，否则"下降 50%"无从比较
- 决定方式：见 [ADR-0003](../02_过程记录/决策记录/ADR-0003_指标换成误动作率.md)

### 2026-10-26 · 题目不改，内涵定为"算力受限下的可信感知"

- 类型：范围
- 原：题目《基于STM32的轻量化目标检测小车》，申报书内容偏工程实现
- 改：题目不动；副标题与全部内容换成三条创新点主线
- 理由：原题目是复现型标题，2018 年已被做透；章程规定不得变更题目
- 影响：**申报书的承诺（实物、源码、报告、论文/专利）全部保留不变**，只是把"做什么最值得做"讲清楚；不构成项目变更
- 决定方式：见 [ADR-0002](../02_过程记录/决策记录/ADR-0002_题目不改内涵换.md)

## 与 `CHANGELOG.md` 的分工

| 文件 | 记什么 | 谁看 |
|---|---|---|
| `CHANGELOG.md`（仓库根） | 仓库内容的变化，按版本归集 | 想了解"这个仓库最近有什么新东西"的人 |
| 本文 | 项目层面的决定与调整 | 想了解"为什么会变成现在这样"的人（评审、指导教师、三个月后的你） |
