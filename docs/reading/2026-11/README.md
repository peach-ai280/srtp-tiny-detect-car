## 三、使用注意

1. 翻译与讲解是**辅助理解材料**，正式引用以原文为准。
2. QMA 的著录若与 Springer 页面不一致，**以页面为准**（卷号、页码曾有过一次订正）。
3. 注意两篇的共同边界，写论文"相关工作"时别写错：
   - 两篇**都没有真实 MCU 部署**（QCore 全部实验在 Titan RTX 工作站上）
   - 两篇**都不做目标检测**（任务是时序分类与图像分类）
   - 两者均**修改模型参数**，而本项目运行期模型冻结、只改车的动作
4. `通俗版` 与 `分析` 是两种东西：本目录只放前者。针对本项目的判断与建议属于个人阅读笔记，未入库。
