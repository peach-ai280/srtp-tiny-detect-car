## 四、术语

统一叫法见 [文档规范](05_规范/04_文档规范.md) 第五节。最容易混的三组：

- **W / U / R** = 可用 / 存疑 / 弃用（三档判定）
- **端到端时延** ≠ **纯推理时延**（前者含抓帧、预处理、后处理、串口）
- **触发率** 与 **覆盖率** 互补（覆盖率 = 1 − 触发率）
