# 新成员上手

> 目标：**一周之内能看懂别人在干什么，两周之内能交第一个小东西。** 不要求一开始就写代码。

---

## 第 0 步 · 先把脑子装上（半天，不碰硬件）

按顺序读，别跳：

1. 仓库根目录 [README](../../README.md) —— 第二节"为什么值得做：一个数"要能自己讲出来（7.2 cm 是怎么算的）
2. [团队章程](01_团队章程.md) —— 知道谁管什么、署名怎么定
3. [实验室规矩](02_实验室规矩.md) —— 尤其是请假和"对自己模块熟悉"两条
4. [AI 使用规范](../05_规范/01_AI使用规范.md) —— 一句话记牢：可以替你想，不能替你测
5. [系统架构](../03_技术方案/01_系统架构.md) —— 画不出框图没关系，要知道有哪几块

读完在群里发三句话：你觉得这个项目最难的地方是什么、最没意思的地方是什么、你想做哪块。**说"最没意思"不用客气，这比客套有用。**

---

## 第 1 步 · 环境（一天，会踩坑，踩完记下来）

| 要装的东西 | 版本 / 说明 | 大概多久 |
|---|---|---|
| STM32CubeIDE | 官网最新稳定版，装完要能新建工程并编译通过 | 1 小时 |
| X-CUBE-AI 扩展包 | 在 CubeIDE 里装，或用 CubeMX 单独装 | 30 分钟 |
| STM32CubeProgrammer | 烧录与读保护设置 | 20 分钟 |
| Python 3.10+ | 建虚拟环境，不污染系统环境 | 20 分钟 |
| Git | 配好 `user.name` / `user.email`，能 `git clone` 本仓库 | 20 分钟 |

**踩到的坑一律记到 `docs/02_过程记录/环境踩坑.md`**（没有就新建），格式一行一条：`现象 → 原因 → 解法 → 来源链接`。这份东西以后是给下一个新人看的，也是给你自己三个月后看的——你一定会忘。

---

## 第 2 步 · 跑通一个最小例子（两天）

不接任何主线任务，只做这一件事：**让一块板子上的 LED 按你的意思闪。**

- 硬件板：先用底盘那块 F103C8T6，不要动 H743（还在采购/未到货的话更不能动）
- 走完整链路：新建工程 → 配 GPIO → 生成代码 → 编译 → 烧录 → 看到现象
- 然后把延时改成 100 ms，再烧一次，确认改动能生效

这一步的意义是**确认你的工具链是通的**。工具链不通的时候，后面所有"代码没问题但就是不动"的排查都会变成玄学。

---

## 第 3 步 · 跟着做一次实验（一天，只观察）

找 A 角约一次实际实验（抓帧、测帧率、电源测试都行），你的任务是：

- 记录实验步骤（按时间顺序，写你看到的，不写你觉得的）
- 记下所有数字和它们的单位
- 记下出问题的地方，以及当时是怎么处理的

实验完把记录整理成一页，作为你的第一个 PR 提交到 `docs/02_过程记录/实验记录/`。**这是你在这份仓库里的第一次留痕。**

---

## 第 4 步 · 第一个 PR（三天内）

从 [Issue 列表](../../.github/ISSUE_TEMPLATE/) 里挑一个 `good first issue`，或者自己提一个"文档补全 / 踩坑记录 / 小脚本"类的。

PR 要求不高，但必须满足：

- [ ] 只做一件事，改动范围说清楚
- [ ] 提交信息按 [提交与分支规范](../05_规范/03_提交与分支规范.md) 写
- [ ] 自己先看一遍 diff，删掉调试残留
- [ ] 有 B 角之外的人看过（哪怕只是看了一遍文档通不通顺）

---

## 上手自检清单

一周结束时，以下每一条都应该能打勾。打不了勾不要紧，写清楚卡在哪，组会上说。

- [ ] 我能不看 README 讲出这个项目要解决的三个问题
- [ ] 我知道自己将来要接哪个模块（M__），它的 A/B 角是谁
- [ ] 我的工具链通了：能编译、能烧录、能看到现象
- [ ] 我已经提交过至少一个 PR（哪怕是改错别字）
- [ ] 我知道请假要怎么请、周报要写哪几栏、AI 用了要写在哪
- [ ] 我至少参加过一次实际实验，并且知道那次实验在验证什么

## 常见误解（提前说，省得走弯路）

| 误解 | 实际 |
|---|---|
| "我大一，先把课上好再来做项目" | 课要上，但项目的时间是靠每周固定投入攒出来的，不是等有空。**每周 6 小时，比考试周一连熬三天有用。** |
| "我先把模型学明白再动手" | 你会在动手的过程中学明白。先跑通一个官方模型，比先看两周理论快。 |
| "文档是给老师看的" | 文档是给三个月后的你和接手的人看的。老师只是顺便看到。 |
| "做不出来很丢人" | 做不出来但说得清，是正常科研；做不出来还编圆了，才是问题。 |
