# 硬件选型与资源账

> 状态：设计稿 v0.1（2026-10-26）。价格为 2026-10 询价，**采购前需复核**。BOM 见 [bom.csv](../../hardware/bom.csv)。

---

## 一、第一个约束是内存，不是主频

选型最容易犯的错是先看主频。对这个项目，**先看内存**——因为 192×192 的检测模型，资源账是这样的（ST model zoo [R2] 实测口径，`st_yolo_lc_v1`）：

| 项 | 大小 | 说明 |
|---|---|---|
| 激活 RAM | 166 KB | 中间张量，跟分辨率强相关 |
| 运行时 RAM | 8 KB | Cube.AI 运行时开销 |
| **RAM 合计** | **174.38 KiB** | |
| 权重 | 277 KB | INT8 参数 |
| 代码 | 53 KB | 算子与框架 |
| **Flash 合计** | **330.21 KiB** | |

于是三个硬门槛：

- **Flash ≥ 660 KB**（留一倍余量给日志字符串、RTOS、应用代码）
- **RAM ≥ 348 KB**（同样留一倍，因为我们还要放帧缓冲和判定模块）
- 主频越高越好，但**排在内存之后**

## 二、为什么是 H743，不是 H750

这是最容易被问的一题，也是我们唯一"贵一点但更省事"的选择。

| | STM32H750VBT6 | **STM32H743VIT6** |
|---|---|---|
| 内部 Flash | **128 KB** | **2 MB** |
| RAM | 1 MB | 1 MB |
| 主频 | 480 MHz | 480 MHz |
| 核心板价格 | 约 60–80 元 | 约 130 元 |

**H750 的 128 KB Flash 装不下 277 KB 的权重。** 这不是"紧一点"的问题，是根本装不下。

要用 H750 就得外挂 QSPI Flash，然后把权重放到外部存储、运行时用内存映射或搬移到 RAM 执行——**多花的钱不多（省 50 元），多踩的坑不少**：启动链路要改（boot 地址、链接脚本、QSPI 初始化顺序），出问题时的现象还很像"程序没烧进去"。

**结论**：多花 50 元买确定性。九个月的项目，坑要留给值得踩的地方。

> 备注：也考虑过 H723/H725（便宜些），但 RAM 只有 320–564 KB，去掉帧缓冲后余量太薄，放弃。

## 三、为什么是核心板，不是开发板

| | 核心板 | 官方开发板（如 Nucleo-H743ZI） |
|---|---|---|
| 价格 | 约 130 元 | 约 300–400 元 |
| 体积 | 小，能装到小车上 | 大，装车困难 |
| 板载调试器 | 无（需 ST-Link） | 有 |
| 引脚 | 全部引出 | 部分被板载外设占用 |

我们要装车，体积是第一位的。调试器可以借/买一个 ST-Link（约 20 元，且实验室通常有）。**如果预算允许，买一块 Nucleo 做"参考平台"是有价值的**——出问题时可对照，判断是硬件问题还是代码问题。当前预算下先不买，遇到疑难再补。

## 五、另两个候选，以及为什么没选

| 器件 | 候选 | 为什么没选 |
|---|---|---|
| 摄像头 | OV5640（500 万像素） | 分辨率对我们没用（模型输入只有 192×192），反而增加 DMA 带宽与预处理开销；[R1] 用的是 5640 但跑 240 ms，我们没必要跟 |
| 测距 | VL53L0X / TOF 激光 | 精度更好、体积更小，但**视场角更窄（约 25°）且是单点**，做"±30° 扫查"需要加舵机，复杂度上升；HC-SR04 便宜、够用、坏了自己换不心疼 |

## 六、供电估算（待徐熠冉实测校正）

| 负载 | 典型电流 | 备注 |
|---|---|---|
| H743 @480 MHz，满负荷推理 | 120–180 mA | 与主频、外设开关强相关，**必须实测** |
| OV2640 | 60–100 mA | 采集时 |
| HC-SR04 ×2（触发时） | 30 mA | 平时休眠接近 0 |
| MPU6050 | 4 mA | |
| F103 + DRV8833 + 4 电机 | 300–900 mA | 取决于负载与占空比 |
| **合计** | **约 0.5–1.3 A** | |

**风险**：单节 18650（2.5–3.5 A 持续能力）在电机启动瞬间会掉压，可能导致 H743 复位——这是"跑着跑着突然重启"最常见的原因，也很容易被误判成"代码有 bug"。

**对策**（按优先级）：
1. 感知板与底盘**分开供电**（各自一路 LDO/DC-DC），至少加一个大电容（470–1000 µF）在感知板电源入口；
2. 电池电压进 ADC 监控，低于阈值时降速并记录；
3. 若仍复位，加 DC-DC 稳压模块（约 10 元）。

**M11（功耗—温升包线）要测的正是这件事**：满负荷连续 30 min，记录电压、电流、板温、帧率，给出"能连续跑多久"的结论。这个数在结题报告里比任何 mAP 都实在。
