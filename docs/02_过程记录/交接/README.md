# 交接

> 按 [实验室规矩](../../04_团队/02_实验室规矩.md) 2.3 节：**请假超过 3 天、或任何原因需要离场时，交一份交接单。**
> 文件名：`YYYY-MM-DD_姓名.md`

---

## 为什么口头交接不算交接

你讲了 15 分钟，对方点头了，然后三天后他打开电脑——不知道从哪开始，不知道你说的"那个文件"是哪个，不知道板子现在是好的还是坏的。

**口头交接的问题不是对方没听，是三天后谁都记不清。** 写下来，是为了让接手的人不用猜。

## 交接三步（缺一步不算完成）

1. **写**：填完上面的模板，提交到本目录。
2. **讲**：当面或语音 15 分钟，接手人可以随时打断提问。**只发文字不算讲。**
3. **跑**：接手人在自己电脑上独立跑一遍，跑不通就当场补文档。**跑通了，交接才算完成。**

---

## 销假

回来当天在群里说一句"已回，接手 M__"，并把交接单的状态改成"已收回"，注明日期。

**不清不楚地回来，等于让替你的人白等。**
