## 内存规划（M1 必须做完的事）

H743 的 RAM 不是一块，是好几块，属性不同：

| 区域 | 大小 | 特点 | 我们放什么 |
|---|---|---|---|
| DTCM | 128 KB | 最快，但**DMA 不能访问** | 栈、关键变量、判定模块状态 |
| AXI SRAM (D1) | 512 KB | 快，DMA 可访问 | 模型激活缓冲、帧缓冲 |
| SRAM1–3 (D2) | 288 KB | 中等 | 大缓冲、日志 |
| SRAM4 (D3) | 64 KB | 最低功耗域 | 串口 DMA 缓冲 |

**最容易踩的坑：把 DMA 缓冲放到 DTCM，然后 DMA 永远搬不动数据，程序卡在等待标志。** 这个现象看起来像"相机坏了"，实际是放错 RAM 区。

M1 的验收要求是**把这张表填成实际分配**，写在 `mem_plan.c` 的注释里，不是口头知道。
