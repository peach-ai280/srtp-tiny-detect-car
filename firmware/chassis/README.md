# 底盘板固件 · STM32F103C8T6

> **状态：底盘硬件已验证（随机器人竞赛搭好），固件需要按本项目需求整理。**
> 这块板是项目的"现有资产"——F103C8T6 + DRV8833 + 60 mm 麦轮。

## 这一块要做什么

一句话：**按感知给的判断动，并在两帧之间自己算清楚位置。**

| 模块 | 文件 | 里程碑 | 干什么 |
|---|---|---|---|
| 电机驱动 | `App/Src/motor.c` | M1（整理） | DRV8833 PWM + 方向，四轮差速/麦轮运动解算 |
| 编码器 | `App/Src/enc_imu.c` | M1 | 四路正交编码器计数，换算成 mm/s |
| IMU | `App/Src/enc_imu.c` | M1 | MPU6050 读陀螺，去零偏 |
| 补位 | `App/Src/extrap.c` | M3–M4 | Q8.8 定点推演，见 [设计文档](../../docs/03_技术方案/05_帧间运动学补位.md) |
| 避障状态机 | `App/Src/ctrl.c` | M4 | W/U/R 三档 → 目标速度 |
| 速度环 | `App/Src/ctrl.c` | M1 | 100 Hz PID |
| 通信 | `App/Src/comm.c` | M1 | 收感知包，回传 (v, ω) 与 tick |
| 日志 | `App/Src/log.c` | M4 | 100 ms 一条，环形缓冲 2000 条，**误动作率全靠它算** |

---

## 三条设计约束

1. **控制环 100 Hz 不能被任何东西阻塞。** 超声测距、串口收发、日志写盘全部异步；不用 `delay()`、不用阻塞式 `pulseIn`。
2. **F103 没有 FPU。** 补位推演全部定点（Q8.8 / Q1.15），三角函数查表。**不要在 10 ms 任务里出现 `float`**——能跑，但会把时间预算吃光，而且哪天时序紧了很难查。
3. **日志必须留痕。** 每个决策（时间、档位、目标速度、实际速度、最近距离）都要记。**没有日志，[ADR-0003](../../docs/02_过程记录/决策记录/ADR-0003_指标换成误动作率.md) 里的误动作率永远算不出来。**

## 100 Hz 循环的骨架（设计，未实现）

```c
void task_ctrl_100hz(void)
{
    /* 1. 采样 */
    int16_t v_meas = enc_get_speed_mm_s();
    int16_t w_meas = imu_get_gyro_z_cdeg_s();

    /* 2. 补位推演（只有视觉框过期时才需要） */
    if (frame_valid) {
        extrap_update(v_meas, w_meas);   /* Q8.8 定点，见设计文档 */
    }

    /* 3. 状态机 → 目标速度 */
    int16_t v_target = plan_get_target(frame_grade,
                                       extrap_get_dist_mm(),
                                       extrap_get_sigma_mm());

    /* 4. 速度环 */
    int16_t duty = pid_step(v_target, v_meas);

    /* 5. 输出 */
    motor_set_duty(duty);

    /* 6. 日志（环形缓冲，不写盘） */
    log_push(millis(), frame_grade, v_target, v_meas, extrap_get_dist_mm());
}
```

**注意第 2 步的条件判断**：只在有有效帧时推演。没有帧的时候推演出来的东西是纯惯性外推，误差会累积——这时应该直接按"最近一次可靠位置 + σ 增大"处理。

## 和感知板的接口

见 [系统架构 · 板间协议](../../docs/03_技术方案/01_系统架构.md) 第四节。要点：

- 收：32 字节定长包（`0xA5` 帧头 + 档位 + 框 + tick + CRC16）
- 发：13 字节定长包（`0x5A` + tick + v + ω + state + CRC16），每 100 ms 一次
- **时钟对齐**：收到包时用"本地时刻 − 包内 tick"更新偏移估计，一阶低通

---

## 按什么顺序做

1. 电机能按给定占空比匀速转（开环）
2. 编码器读数校准成 mm/s（用卷尺量 1 m，走 10 次取平均）
3. PID 定速（目标 0.3 m/s，误差 < 5%）
4. IMU 陀螺零偏标定（静止 10 s 取均值）
5. 串口收发与 tick 对齐（误差 < 5 ms）
6. 补位推演（先离线仿真核对符号，见设计文档第七节）
7. 状态机接上三档

**第 2 步和第 3 步做扎实，后面所有实验数据才可信。** 编码器换算错了，横向偏差、补位收益全都测不准。
