## 接线（M1 完成后补全）

> 现在写不出准确的接线表，因为核心板还没到货、引脚分配未定。**到货后第一件事就是把这张表填上，并在每次改线后更新。**
> 不更新接线表的后果：三周后忘了某根线为什么这么接，只能一根一根试。

| 信号 | 感知板引脚 | 对方 | 备注 |
|---|---|---|---|
| DCMI_D0–D7 | 待定 | OV2640 D0–D7 | 注意数据位顺序，接反了图像会是花屏 |
| DCMI_PIXCLK | 待定 | OV2640 PCLK | |
| DCMI_VSYNC/HSYNC | 待定 | OV2640 | |
| I²C1_SCL/SDA | 待定 | OV2640 SCCB | **OV2640 的配置口叫 SCCB，电气上是 I²C** |
| UART_TX/RX | 待定 | F103 UART | 两板通信，交叉接（TX→RX） |
| TRIG ×2 | 待定 | HC-SR04 | 触发输出 |
| ECHO ×2 | 定时器输入捕获 | HC-SR04 | **5 V 回波，H743 是 3.3 V——必须分压或电平转换，否则烧引脚** |
| 电源 | 5 V / GND | 电池经稳压 | 感知板与底盘建议分路供电 |

**两个必须提前说的坑**：

1. **HC-SR04 的 ECHO 是 5 V 输出。** 直接接 3.3 V 的 MCU 引脚，轻则读数异常，重则烧 IO。用两个电阻分压（1k + 2k）即可。
2. **OV2640 模块有 3.3 V 和 5 V 版本。** 买的时候看清，接错直接不工作。

## 机械

- 第二块板需要固定位置：优先放在底盘上层，避开轮子行程
- 摄像头要有俯角（约 20–30°），看得见前方 15–80 cm 的地面
- 超声安装高度与物料盒中心齐平（约 5–10 cm），否则测到的是盒子顶部或地面
- 结构件走 3D 打印（预算里 350 元测试加工费就是这项）

## 采购注意

| 器件 | 注意什么 |
|---|---|
| H743 核心板 | 必须 **VIT6**（100 脚 / 2 MB Flash）；别买成 H750（128 KB Flash，装不下模型）；买带外部晶振的版本 |
| OV2640 | 确认 3.3 V 版本；带 DCMI 排线 |
| HC-SR04 | 便宜，多买两个备用（易损） |
| MPU6050 | 假货多，优先买带电平转换的模块 |
| 18650 电池 | 认准持续放电 ≥ 3 A 的；配保护板；**充电器单独买，别用杂牌** |

## 安全（写在这里，不是走过场）

1. **带电不插拔电机线。** 反电动势能烧驱动。
2. **调试时把车架空。** 轮子突然转起来会打断手指，也会把桌面的东西扫下去。
3. **18650 不短路、不反接、不挤压。** 短路会起火。电池发热立即断开。
4. **超声对人耳无影响，但激光（如果以后加 TOF）不能照眼。**
5. **电烙铁用完断电，别放在桌边。**
